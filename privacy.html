1. 개인정보처리방침 개요

때온은 생활용품 구매 기록을 바탕으로 다음 구매 시점을 예상하고 재구매 알림을 제공하는 개인 생활용품 재구매 관리 서비스입니다. 이 방침은 현재 서비스에서 처리하는 정보, 그 목적과 저장 방식, 이용자의 선택권을 설명합니다.

현재 Android 앱은 회원가입·로그인·강제 클라우드 계정 없이 사용하는 로컬 중심 MVP이며, 구매 이력과 규칙을 바탕으로 재구매일을 예상합니다. 클라우드 동기화와 서버 계정 기능은 현재 제공하지 않습니다.

2. 서비스에서 처리하는 정보

사용자가 직접 입력하거나 Android 공유를 통해 등록한 정보 및 이를 바탕으로 생성되는 정보는 다음과 같습니다.

  • 상품명, 생활용품 카테고리
  • 구매일, 구매가격, 구매수량, 구매 이력
  • 상품 URL, 상품 식별 정보(productId, itemId, vendorItemId 등)
  • 예상 재구매일 및 알림 상태
  • 사용자가 앱으로 직접 공유한 텍스트와 URL

구매가격은 사용자가 실제 결제 내용을 확인하여 입력·수정할 수 있습니다. 현재 쿠팡 가격 자동 조회나 가격 추적 기능은 제공하지 않습니다.

현재 확인된 구현에는 정밀 위치·연락처·카메라·마이크·사진·SMS 정보를 수집하는 기능이 포함되어 있지 않습니다. 이 방침은 확인되지 않은 권한이나 수집 항목을 추가하지 않습니다.

3. 정보 이용 목적

  • 구매 기록의 등록·조회·수정·삭제
  • 생활용품별 구매 이력과 개인 구매 간격 관리
  • 구매 간격과 수량을 반영한 예상 재구매일 계산
  • 재구매 알림 및 알림 미루기 관리
  • 최근 구매 상품 확인 및 저장된 상품 페이지 연결

예상일은 구매 기록에 기반한 참고 정보이며, 실제 소비 속도나 필요 시점과 다를 수 있습니다. 현재 AI API를 이용한 소비 예측이나 상품 추천 기능은 제공하지 않습니다.

4. 정보 저장 방식

핵심 구매 기록과 재구매 예측 데이터는 현재 기기 내부의 로컬 SQLite 데이터베이스에서 관리됩니다. 현재 앱에는 서버 계정이나 클라우드 동기화 기능이 없습니다.

기기 내 데이터 저장과 외부 상품 URL 처리는 구분됩니다. 쿠팡 단축 URL 처리 및 외부 상품 페이지 연결 과정에는 외부 서비스와의 네트워크 통신이 수반될 수 있습니다. 실제 공개 버전의 통신 범위와 운영체제 백업 설정은 공개 전에 확인하여 이 방침에 반영해야 합니다.

이 소개 웹사이트에는 분석 도구, 추적 SDK, 광고 SDK 및 광고 쿠키를 추가하지 않았습니다. 향후 호스팅 제공자를 선정하면 해당 제공자의 접속 로그 등 처리 여부를 별도로 확인해야 합니다.

5. Android 공유 기능

사용자는 쇼핑 앱이나 상품 페이지에서 Android 공유 기능을 선택하여 텍스트 또는 URL을 때온으로 직접 전달할 수 있습니다. 앱은 공유된 내용을 구매 등록에 활용할 수 있습니다.

이 기능은 사용자가 공유하지 않은 브라우저 방문 기록 전체를 읽는 기능이 아닙니다. 구매 등록 내용은 사용자가 확인하며, 직접 입력하는 방식도 선택할 수 있습니다.

6. 외부 서비스 연결

사용자가 “다시 구매하기”를 선택하면 최근 구매 상품을 확인하고, 확인 창을 거쳐 저장된 HTTPS 상품 URL로 외부 쿠팡 앱 또는 브라우저를 열 수 있습니다. 현재 앱은 해당 흐름에 WebView를 사용하지 않습니다.

최근 구매에 안전한 쿠팡 상품 URL이 없는 경우, 과거 쿠팡 상품을 임의로 대신 연결하지 않습니다. 외부 서비스에서는 해당 사업자의 약관과 개인정보처리방침이 적용될 수 있으며, URL에 포함된 상품 식별 정보가 해당 서비스에 전달될 수 있습니다.

웹사이트의 생활용품 추천 페이지에서 상품 보기 링크를 선택하면 쿠팡 파트너스 제휴 링크를 통해 외부 쿠팡 사이트가 새 창에서 열립니다. 이 링크는 제휴 식별 정보를 포함할 수 있으며, 외부 서비스의 데이터 처리에는 해당 사업자의 정책이 적용됩니다. 외부 페이지에서 이루어지는 주문·결제 및 데이터 처리에 대해서는 해당 서비스의 안내를 확인해 주세요. 때온은 사용자의 쿠팡 구매 여부나 구매내역을 직접 수집하지 않으며, 구매 완료를 자동으로 판정하지 않습니다.

7. 알림 권한

Android 알림 권한은 재구매 알림을 제공하기 위해 사용합니다. 현재 알림은 기기에서 제공되는 로컬 알림이며, 서버 푸시 또는 FCM 기반 서비스가 아닙니다.

기본적으로 예상 재구매일보다 7일 전에 알림을 제공하는 구조이며, 사용자는 알림을 7일·14일·30일 미룰 수 있습니다. 알림 권한을 허용하지 않아도 구매 기록과 재구매일 예상 등 핵심 기능을 사용할 수 있습니다. 권한은 Android 설정에서 변경할 수 있습니다.

8. 제3자 제공

현재 제공된 앱 구현 상태에는 핵심 구매 기록을 운영자 서버 또는 제휴 분석 시스템으로 제공하는 기능이 포함되어 있지 않습니다. 사용자가 외부 상품 페이지를 열 때 발생하는 URL 전달 및 외부 서비스의 처리는 제6항을 참고해 주세요.

웹사이트의 생활용품 추천 페이지에는 쿠팡 파트너스 제휴 링크가 포함되어 있습니다. 사용자가 이 링크를 통해 구매하면 때온 운영자가 일정액의 수수료를 제공받을 수 있습니다. 현재 사이트 자체에는 클릭 추적 스크립트나 구매 여부·구매내역을 직접 수집하는 기능이 없습니다. 외부 제휴 링크 선택에 따른 이동과 해당 서비스의 데이터 처리는 제6항을 참고해 주세요. 앱의 쿠팡 파트너스 API 연동이나 제휴 기능을 구현했다는 의미는 아닙니다.

9. 데이터 보유 및 삭제

현재 핵심 앱 데이터는 이용자의 기기 내부에 저장되며, 앱에서 개별 구매 기록을 삭제할 수 있습니다. 운영자 서버에 저장되는 구매 기록에 대한 보유기간은 현재 구조에서 적용되지 않습니다.

앱 삭제 또는 Android 설정의 앱 데이터 삭제가 데이터에 미치는 영향은 운영체제의 처리 방식, 백업·복원 설정 등에 따라 달라질 수 있습니다. 삭제 전 필요한 기록을 확인하고, 기기 설정 및 백업 상태를 함께 확인해 주세요. 앱에는 현재 클라우드 동기화 기능이 없습니다.

향후 계정 또는 클라우드 기능이 추가되면 저장 위치, 보유기간 및 삭제 절차를 다시 안내할 예정입니다.

10. 이용자의 선택권

  • 구매 정보를 직접 등록하거나, 원하는 텍스트와 URL만 공유할 수 있습니다.
  • 앱에서 구매 기록을 조회·수정·삭제할 수 있습니다.
  • Android 설정에서 알림 권한을 허용하거나 거부할 수 있습니다.
  • 알림을 미루고 외부 상품 페이지를 열지 않을 수 있습니다.

정보 처리에 관한 문의는 제13항의 문의 이메일을 이용해 주세요.

11. 아동 관련 정책

현재 앱에는 연령 확인, 법정대리인 동의 또는 아동 전용 계정 기능이 구현되어 있다는 정보가 제공되지 않았습니다. 아동을 대상으로 별도 정보를 수집하는 기능도 현재 확인된 구현에 포함되어 있지 않습니다.

실제 서비스의 이용 대상 연령과 아동 관련 운영 정책은 공개 전에 운영자가 확정해야 합니다. 만 14세 미만 아동의 개인정보를 처리하는 서비스로 운영할 경우 적용되는 동의 및 보호 절차를 검토하고 이 방침에 반영해야 합니다. 이 초안은 해당 절차가 마련되어 있음을 의미하지 않습니다.

12. 개인정보처리방침 변경

서비스 기능이나 정보 처리 방식이 변경되면 이 방침을 수정하고 시행일과 변경 내용을 웹사이트 또는 서비스 화면에서 안내할 예정입니다. 향후 클라우드·계정 기능이 도입되거나 제휴 링크의 데이터 처리 방식이 변경되면 실제 처리 내용을 이 방침에 반영합니다.

현재 초안 기준 시행일은 2026년 10월 6일입니다. 실제 공개일과 다를 경우 공개 전에 시행일을 수정해야 합니다.
